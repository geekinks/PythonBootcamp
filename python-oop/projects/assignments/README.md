# 📚 Practical OOP Project Assignments

Welcome to the Course Assignments directory. These assignments test your ability to synthesize Object-Oriented Programming concepts into complete, working, multi-entity software systems.

## 🎯 Submission Requirements
For each assignment:
1. Create a dedicated project folder inside `projects/` (or your personal workspace).
2. Separate your classes into clean, focused Python modules.
3. Write a comprehensive `main.py` demonstrating typical usage scenarios.
4. Include automated unit tests (`unittest` or `pytest`) testing happy paths and boundary conditions.
5. Provide a `design.md` with Mermaid class diagrams justifying your architectural choices.
