# 🧪 Python OOP Practical Exercises

Welcome to the hands-on exercise track for the Python OOP curriculum.

## 🎯 How the Exercises Work
Every exercise directory follows a standard structure:
```text
exercise-directory/
├── README.md      # Problem scenario, requirements, hints & extension challenge
├── starter.py     # Skeleton code with TODO comments and runnable test assertions
└── solution.py    # Complete reference solution with explanatory comments
```

---

## 🚦 Difficulty Progression

- 🟢 **Beginner**: Complete missing lines of code and grasp fundamental syntax.
- 🟡 **Intermediate**: Modify and extend existing classes, implement properties and validation.
- 🔴 **Challenge**: Design multiple interacting classes, apply design patterns, and protect system invariants.

## 🛠️ How to Work on Exercises
1. Navigate into an exercise folder (e.g. `cd exercises/01-classes-and-objects`).
2. Read the `README.md` for context and requirements.
3. Open `starter.py` and implement the requested `TODO` sections.
4. Run `python3 starter.py` to execute the built-in test assertions.
5. If you get stuck, review the lecture notes or consult `solution.py`.
